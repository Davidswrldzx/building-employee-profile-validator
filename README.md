# Building and Employee Profile Validator 🐍

## About this project

I'm learning Python using freeCodeCamp. This is a beginner workshop where I practiced working with strings by cleaning and checking employee information and building addresses.

I'm still learning, so this repository is a record of the methods I practiced and what I understood along the way. It is **a learning exercise**, not a complete employee management application.

## What I practiced

- Creating variables and printing text with f-strings
- Finding `@` in an email using `.find()` and extracting a username with slicing
- Checking for text using `in`
- Cleaning names using `.strip()` and `.title()`
- Cleaning email addresses using `.strip()` and `.lower()`
- Creating uppercase name badges with `.upper()`
- Replacing characters with `.replace()`
- Splitting addresses with `.split()` and joining them with `.join()`
- Checking prefixes and suffixes with `.startswith()` and `.endswith()`
- Counting characters with `.count()`
